# 📚 FBS – E-Books Website

## 📖 About the Project

FBS E-Books Website is a simple front-end web development project designed to provide users with an interface for browsing an e-book website, accessing login and registration forms, and viewing a shopping cart.

The project is developed using **HTML, CSS, and JavaScript**. It demonstrates website layout design, form validation, navigation between pages, and basic shopping cart presentation.

## ✨ Features

- **Home Page:** Welcome page introducing the FBS E-Books Website.
- **Login Page:** Login form with username and password validation.
- **Registration Page:** Registration form with validation for username, password, email, phone number, gender, languages known, and address.
- **Shopping Cart:** Displays book names, prices, quantities, and total amount.
- **Form Validation:** JavaScript checks user inputs and displays validation messages.
- **Navigation Bar:** Easy navigation between Home, Login, Registration, and Cart pages.
- **CSS Styling:** Consistent layout with headers, footers, sidebars, and content sections.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and layout
- JavaScript – Client-side form validation

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure all HTML pages and the CSS file are in the correct locations.
4. Install the **Live Server** extension in VS Code if you haven't already.
5. Right-click `index.html`.
6. Select **Open with Live Server**.
7. Use the navigation bar to visit the Login, Registration, and Cart pages.

Alternatively, open `index.html` directly in your web browser.

## 🧪 Form Validation

The project demonstrates client-side validation, including:

- Checking that required fields are filled in.
- Validating username and password lengths on the registration page.
- Checking email format.
- Checking for a 10-digit phone number.
- Ensuring that a gender and at least one language are selected.
- Checking that shopping cart quantities are positive integers.

## 🎯 Project Objective

The objective of this project is to understand the fundamentals of front-end web development, create a multi-page website, implement JavaScript form validation, and organize website files for a working user interface.
